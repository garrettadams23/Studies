🧮 Systems of Equations — One Solution, None, or Infinitely Many LINALG • Systems ▶
Core Concept

The picture gives the count before any algebra

A system of linear equations is a set of equations in the same unknowns, each one a line (two unknowns), a plane (three) or a hyperplane (more). A solution is a point on all of them at once, so the number of solutions is a question about how the shapes meet, and there are only three possible answers. There is never exactly two.

Two lines…SolutionsWhat the algebra shows
Cross at one pointExactly oneDifferent slopes. Row reduction gives a pivot for every unknown
Run parallelNone (inconsistent)Same slope, different intercept. A row reduces to 0 = 5
Coincide — the same line twiceInfinitely manyOne equation is a multiple of the other. A row reduces to 0 = 0 and an unknown is left free
Sketch or compare slopes first, because the last two rows look identical until the right-hand side is checked. 2x + 4y = 6 and x + 2y = 3 are one line; change the 3 to a 4 and they never meet. The left sides are the same either way — only the constants decide which of the bottom two rows you are in.
Counting

What the shape of the system tells you before you solve it

System shapePossible answersWhy
Homogeneous (every constant is 0): Ax = 0One or infinitely many — never nonex = 0 always works. The only question is whether anything else does
More unknowns than equationsNone or infinitely many — never exactly oneThere are more columns than there can be pivots, so at least one unknown is free
Square (n equations, n unknowns)Exactly one if and only if det A ≠ 0A non-zero determinant means a pivot in every column; see Determinants — Cofactor Expansion & What Row Operations Do to Them
More equations than unknownsAny of the three; usually noneExtra equations are extra constraints. When data gives too many, the answer is least squares
The second row is the one tests use to save you work. Two equations in three unknowns cannot have a unique solution, so an answer option that gives a single point is wrong before any arithmetic. The first row is its mirror: a homogeneous system that "has no solution" means an arithmetic slip, because zero is always one.
Vocabulary

The words, and one convention that is not a definition

WordMeaning
ConsistentHas at least one solution
InconsistentHas none
Solution setEvery solution, written as a point, a parametric form (x = 3 − 2t, y = t) or the empty set
Equivalent systemsTwo systems with the same solution set — what every row operation preserves
LinearEach unknown appears to the first power, multiplied only by a constant. xy, x², sin x or 1/x make it non-linear

Some courses say a system "needs at least two equations." That is a convention for what the course will call a system, not part of the definition. One linear equation is a perfectly good (trivial) system, and its solution set is a line or a plane. If a quiz asks, answer the way your course defines it; on any other test, one equation counts.

Applied

The input–output model: an economy as one system

Course notes that start talking about inputs and outputs — what a factory consumes, what it ships — are usually leading up to the Leontief input–output model. Each industry uses some of every other industry's output to make its own. With C the consumption matrix (column j is what industry j uses per unit it produces) and d the outside demand, the production x that exactly meets demand solves:

x = Cx + d          # production = internal use + outside demand
(I − C)x = d        # one linear system

C = | 0.2  0.3 |    d = | 100 |
    | 0.4  0.1 |        |  50 |

I − C = |  0.8  −0.3 |      det = 0.72 − 0.12 = 0.60
        | −0.4   0.9 |

x = (I − C)⁻¹ d = (1/0.6) | 0.9  0.3 | | 100 |  =  | 175.0 |
                          | 0.4  0.8 | |  50 |     | 133.3 |

CHECK: 0.8(175) − 0.3(133.3) = 100 ✓     −0.4(175) + 0.9(133.3) = 50 ✓
Check the syllabus for this model by name before the test. If the notes have an inputs-and-outputs vocabulary list and no matrix, the matrix is what the next lecture adds, and it is the part that is examined.
🪜 Row Reduction — Gaussian Elimination, RREF & Reading the Answer LINALG • Method ▶
Core Concept

The augmented matrix and the three moves

Write the system as an augmented matrix [A | b]: the coefficient matrix A with the constants b as an extra column. Gaussian elimination then uses only three row operations, and none of them changes the solution set — which is the entire reason the method is allowed.

Row operationNotationEffect on a determinant
Replace a row with itself plus a multiple of anotherR₂ → R₂ − 2R₁None
Swap two rowsR₁ ↔ R₂Flips the sign
Multiply a row by a non-zero constantR₃ → ½R₃Multiplies it by that constant
The first row does almost all the work, and "non-zero" in the last row is the rule people break. Multiplying a row by 0 deletes an equation and changes the answer. The third column matters later, in the determinants card, where these same moves are the fast way to a determinant.
Definitions

Row echelon form vs reduced row echelon form (REF vs RREF)

Row echelon form (REF)Reduced row echelon form (RREF)
Zero rowsAt the bottomAt the bottom
Each pivot (leading entry)Is to the right of the pivot above itIs to the right of the pivot above it, and is 1
Column of each pivotZeros below itZeros above and below it
Unique?No — many REFs per matrixYes — exactly one
Reading the answerNeeds back-substitutionRead it straight off
The uniqueness row is why answer keys use RREF. Two correct people can reach different echelon forms, but never different reduced ones, so a marker can only check RREF at a glance. Here pivot is the leading entry of a row — nothing to do with pivoting through a network, which is the sense the rest of this site uses.
Reading the answer

The bottom row decides everything

What RREF showsMeaning
A row [0 0 0 | 5] — zeros, then a non-zero constantNo solution. That row says 0 = 5. Stop; nothing else matters
A pivot in every variable columnExactly one solution, read off the last column
A variable column with no pivot, and no 0 = 5 rowInfinitely many solutions. That variable is free; write the others in terms of it
A row [0 0 0 | 0]Says 0 = 0: one equation was redundant. On its own it proves nothing about the count
Check for the first row before anything else. A 0 = 0 row is the classic misreading: it does not mean infinitely many solutions by itself — that comes from a column without a pivot. Count pivots against variables, not zero rows.
Hands-on

One system, both endings

#  x + 2y +  z = 4        augmented matrix
# 2x + 4y + 3z = 9
#  x + 2y + 2z = 5

| 1 2 1 | 4 |
| 2 4 3 | 9 |   R₂ → R₂ − 2R₁   ->  | 0 0 1 | 1 |
| 1 2 2 | 5 |   R₃ → R₃ − R₁    ->  | 0 0 1 | 1 |
                R₃ → R₃ − R₂    ->  | 0 0 0 | 0 |
                R₁ → R₁ − R₂    ->  | 1 2 0 | 3 |

RREF:  | 1 2 0 | 3 |     pivots in x and z; y has none, so y is FREE
       | 0 0 1 | 1 |
       | 0 0 0 | 0 |

Solution:  x = 3 − 2t,  y = t,  z = 1      # infinitely many
"Set the free variable to 0":  (3, 0, 1)
CHECK in row 2 of the original: 2(3) + 4(0) + 3(1) = 9 ✓

# Now change the last constant from 5 to 6:
R₃ − R₁ gives | 0 0 1 | 2 |,  then R₃ − R₂ gives | 0 0 0 | 1 |
That row says 0 = 1.  No solution.

The coefficients never changed between the two endings — only one constant did. That is the systems card's point made in a matrix: the left-hand side decides whether an unknown is free, and the right-hand side decides whether there is anything to be free about.

On a computer

Why software swaps rows you would not, and what the condition number bounds

By hand you pick the friendliest pivot. Software uses partial pivoting: in each column it swaps up the row with the largest absolute value. The reason is floating point — in binary 0.1 + 0.2 is not exactly 0.3 (see Number Representation — Two's Complement, IEEE-754 & the Bugs Each Causes), and dividing by a tiny pivot multiplies that rounding error into the whole answer.

The condition number κ(A) measures how sensitive a system is. The rule usually quoted as "output error ≈ condition number × input error" is an upper bound, not an estimate: the relative error in x is at most κ(A) times the relative error in b. The matrix [1 1; 1 1.0001] has κ ≈ 40,000 — two nearly parallel lines, where a nudge to either moves the crossing point a long way.

Gaussian elimination is also why one family of post-quantum cryptography works. A system with small random errors added to every equation cannot be row-reduced back to its secret; remove the errors and elimination recovers it at once. Lattices, Gently — The Hard Problem Post-Quantum Cryptography Moved To tells that story from the security side.

🔲 Determinants — Cofactor Expansion & What Row Operations Do to Them LINALG • Method ▶
Core Concept

One number: how much the matrix scales area, and whether it flattens

For a 2×2 (2x2) matrix the determinant is det [a b; c d] = ad − bc. Geometrically it is the factor by which the matrix scales area (volume, in 3D); a negative sign means it also flips orientation, like a mirror. A determinant of zero means the matrix squashes space into a lower dimension — a plane onto a line — and nothing can un-squash it, which is why det A = 0 is exactly the test for "no inverse".

The matrix sense of the word is the only one meant here. Elsewhere on this site a determinant is a database term, in normalization, and the two have nothing to do with each other.

Method

Cofactor expansion — a determinant of a 3x3 by hand

Pick any row or column. For each entry aᵢⱼ, delete its row and column to get a smaller submatrix; its determinant is the minor Mᵢⱼ, and the cofactor is Cᵢⱼ = (−1)i+j Mᵢⱼ. The determinant is the sum of each entry times its cofactor along that one row or column. The signs follow a checkerboard that always starts with + in the top-left:

| + − + |        A = | 2 0 1 |
| − + − |            | 3 1 0 |
| + − + |            | 1 4 5 |

Along row 1:
det A = +2·det| 1 0 |  − 0·(anything)  + 1·det| 3 1 |
              | 4 5 |                         | 1 4 |
      = 2(5 − 0)   −   0   +   1(12 − 1)
      = 10 + 11 = 21
Expand along the row or column with the most zeros. The 0 in row 1 above removed a whole 2×2 calculation. The sign of a cofactor comes from its position, never from the entry — a negative entry in a + position is still added.
The fast way

Row-reduce to triangular, then multiply the diagonal

Do this to the matrixThe determinant
Add a multiple of one row to anotherDoes not change
Swap two rowsChanges sign
Multiply one row by kIs multiplied by k
Reach a triangular matrixIs the product of the diagonal
Find a row of zeros, or two equal rowsIs 0 — stop
| 0 2 4 |   R₁ ↔ R₂ (sign flips)   | 1 1 1 |   R₃ − 2R₁   | 1 1 1 |   R₃ − R₂   | 1 1 1 |
| 1 1 1 |  ----------------------> | 0 2 4 |  ---------> | 0 2 4 |  --------> | 0 2 4 |
| 2 4 8 |                          | 2 4 8 |             | 0 2 6 |            | 0 0 2 |

diagonal: 1 · 2 · 2 = 4,  one swap  ->  det = −4
A swap flips the sign and a row replacement changes nothing, so reduce to triangular and multiply the diagonal. For anything bigger than 3×3 this is the only sane method — cofactor expansion of a 5×5 is 120 products. Keep a tally of swaps and scalings as you go; that tally is the only thing that can go wrong.
The trap

The properties that are true, and the two that are not

TrueNot true
det(AB) = det A · det Bdet(A + B) = det A + det B — no such rule
det(Aᵀ) = det A, so column operations behave like row operationsdet(kA) = k · det A — it is kⁿ · det A for an n×n matrix, because every row is scaled
det(A⁻¹) = 1 / det A
The kⁿ row is the one that costs marks. Doubling a 3×3 matrix multiplies its determinant by 8, not 2. And the diagonal shortcut called Sarrus's rule works for 3×3 only — applied to a 4×4 it gives a confident wrong number.
↩️ Inverse Matrices — The 2-by-2 Formula, Solving Ax = b & When There Is None LINALG • Method ▶
Core Concept

The inverse of a 2x2 matrix: swap, negate, divide

The inverse A⁻¹ undoes A: A⁻¹A = AA⁻¹ = I. Only square matrices can have one, and only when det A ≠ 0. For a 2×2 there is a formula worth knowing cold — swap the diagonal, negate the off-diagonal, divide by the determinant:

A = | a b |        A⁻¹ = 1/(ad − bc) · |  d  −b |
    | c d |                            | −c   a |

A = | 4 7 |        det = 24 − 14 = 10
    | 2 6 |
                   A⁻¹ = 1/10 · |  6 −7 |  =  |  0.6 −0.7 |
                                | −2  4 |     | −0.2  0.4 |

CHECK (multiply back):  row 1 of A · column 1 of A⁻¹ = 4(0.6) + 7(−0.2) = 1 ✓
                        row 1 of A · column 2 of A⁻¹ = 4(−0.7) + 7(0.4) = 0 ✓
Check the determinant before inverting and multiply back after. The first catches the matrices with no inverse before you divide by zero; the second catches the sign slip in the formula, which is the commonest error on this card.
Method

Bigger than 2×2: row-reduce [A | I]

Put the identity beside A and row-reduce the whole thing. If the left half becomes I, the right half is A⁻¹. If the left half produces a row of zeros, A has no inverse and you can stop there — that row is the same finding as a zero determinant.

[ A | I ]   --row operations-->   [ I | A⁻¹ ]
                                  or a zero row on the left: not invertible
Equivalences

Seven ways of saying "invertible", cheapest test first

For an n×n matrix A, each of these is the same factWhen to use it
det A ≠ 02×2 and 3×3 — seconds by hand
A has n pivots (its RREF is I)When you are row-reducing anyway
The columns are linearly independentWhen a question is about vectors, not equations
Ax = 0 has only the solution x = 0Proofs, and null space questions
Ax = b has exactly one solution for every bSystems questions
Rank is n; the null space is just {0}Rank questions
0 is not an eigenvalueEigenvalue questions
Prove one row and you have proved all seven. This is the invertible matrix theorem, and its use on a test is translation: a question phrased about columns can be answered with a determinant, and a question about eigenvalues with a row reduction.
Solving Ax = b

Nothing divides a matrix — order is everything

There is no matrix division. To solve Ax = b you multiply both sides by A⁻¹ on the left, giving x = A⁻¹b. Because AB ≠ BA (see Matrices & Linear Transformations — The Operation a GPU Spends Its Life Doing), the side matters every time:

EquationSolution
AX = BX = A⁻¹B
XA = BX = BA⁻¹
(AB)⁻¹B⁻¹A⁻¹ — reversed, like taking off socks and shoes

In code, NumPy (installed with pip; see Modules, Packages & pip — Using Other People's Code) gives both routes, and the professional habit is to solve rather than invert — it is faster and loses less precision:

import numpy as np
A = np.array([[4, 7], [2, 6]])
b = np.array([1, 2])

np.linalg.solve(A, b)     # array([-0.8,  0.6])   preferred
np.linalg.inv(A) @ b      # array([-0.8,  0.6])   same answer, more work
np.linalg.det(A)          # 10.000000000000002    floating point, not 10
On paper, use the inverse when the question asks for it; in code, use solve. The determinant printing as 10.000000000000002 is the floating point story from the row reduction card, and it is why det(A) == 0 is never the right test in code — compare against a small tolerance instead.
