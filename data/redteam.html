Authorized Use Only
These Tools Are for Permission-Based Testing
Every tool in this domain is a reference for authorized penetration testing, CTF competitions, home-lab practice, and cert prep (PenTest+, OSCP, CEH). Running them against systems you don't own or lack written permission to test is illegal in most jurisdictions (CFAA, Computer Misuse Act, etc.). Each card pairs offense with a blue-team detection note — because knowing how an attack looks on the wire is what makes you good at both sides.
🗺️ Nmap — The Network Mapper (Deep Dive) Recon ▶
Reference
The Swiss-Army Knife of Discovery
Nmap is the default tool for host discovery, port scanning, service/version detection, and OS fingerprinting. Its scripting engine (NSE) extends it into vuln checks and light exploitation. Authorized targets only.
▸ SCAN TYPES & ESSENTIALS
nmap -sS 10.0.0.0/24        # SYN "half-open" scan (default, fast, needs root)
nmap -sT target             # full TCP connect (no root)
nmap -sU target             # UDP scan (slow; DNS/SNMP/DHCP live here)
nmap -sV -O target          # service versions + OS detection
nmap -p- target             # all 65535 ports (default scans top 1000)
nmap -sC -sV -oA scan target # default scripts + versions, save all formats
nmap -T4 -Pn target          # faster timing; skip host-discovery ping
▸ NSE (SCRIPTING ENGINE)
FlagDoes
-sCRun the default safe script set
--script vulnKnown-vuln checks
--script smb-enum-sharesCategory/named scripts (~600 available)
-AAggressive: -sV -O -sC + traceroute
Blue-team note: a SYN scan shows up as many connections with no completed handshake from one source — IDS (Suricata/Zeek) and firewall logs flag the fan-out. -T4/-T5 timing is loud; real adversaries scan slow.
⚡ Masscan & RustScan — Internet-Scale Port Discovery Recon ▶
Reference
When Nmap Is Too Slow
Masscan is an asynchronous scanner that can probe the entire IPv4 space in minutes by sending packets without waiting for replies. RustScan finds open ports fast, then hands them to Nmap for deep inspection — best of both. Authorized scope and rate limits only; unbounded scanning is disruptive. 
# Masscan — set a sane rate (packets/sec); high rates can DoS the target
masscan 10.0.0.0/16 -p1-65535 --rate 1000 -oL out.txt

# RustScan → auto-pipe discovered ports into nmap -sV -sC
rustscan -a target --range 1-65535 -- -sV -sC
Blue-team note: extremely high packet rates from a single IP to sequential ports are the signature — netflow/IDS thresholds catch it instantly. Attackers throttle to blend in.
🌾 theHarvester & Recon-ng — OSINT Frameworks OSINT ▶
Reference
Passive Intelligence Before You Touch the Target
theHarvester gathers emails, subdomains, hosts, and names from public sources (search engines, certificate transparency, PGP keyservers). Recon-ng is a full framework with a Metasploit-style module system for structured OSINT into a local database. These are passive — they query third parties, not the target directly. 
theHarvester -d example.com -b all      # emails/subdomains from all sources

# Recon-ng — modular, DB-backed
recon-ng
[recon-ng] > marketplace install all
[recon-ng] > modules load recon/domains-hosts/hackertarget
[recon-ng] > options set SOURCE example.com
[recon-ng] > run
Blue-team note: passive OSINT is nearly invisible to the target — the defense is reducing your footprint: scrub metadata, limit what's public, monitor certificate-transparency logs for look-alike domains.
🔭 Amass & Subfinder — Subdomain Enumeration OSINT ▶
Reference
Mapping the Full Attack Surface
Organizations expose far more subdomains than they realize — dev, staging, forgotten apps. Amass (OWASP) and Subfinder aggregate dozens of sources (cert transparency, DNS, APIs) to enumerate them. Finding the forgotten old-admin.example.com is often the way in. 
subfinder -d example.com -all -o subs.txt   # fast, passive
amass enum -passive -d example.com            # passive aggregation
amass enum -active -d example.com -brute       # active: resolves + brute-forces
Blue-team note: maintain your own asset inventory the same way — you can't defend subdomains you forgot you own. Watch for dangling DNS records (subdomain takeover risk).
🛰️ Shodan & Censys — Search Engines for Exposed Devices OSINT ▶
Reference
The Internet, Already Scanned for You
Shodan and Censys continuously scan the internet and index every exposed service — banners, ports, TLS certs, default logins, ICS/SCADA, webcams. Searching them is passive (you query their database, not the target), making them a favorite first step.
▸ SHODAN SEARCH FILTERS

Blue-team note: search Shodan/Censys for your own org regularly — it's the fastest external-exposure audit there is. Anything you find, an attacker already has.
🔎 Google Dorking, Maltego & SpiderFoot OSINT ▶
Reference
Advanced Search & Automated Link Analysis
Google Dorking uses advanced operators to surface exposed data indexed by search engines (the Google Hacking Database catalogs thousands of proven queries). Maltego and SpiderFoot automate OSINT into visual link graphs — connecting domains, emails, people, and infrastructure.
▸ USEFUL DORKS
OperatorFinds
site:example.com filetype:pdfDocuments on a domain
intitle:"index of" site:example.comOpen directory listings
inurl:admin site:example.comAdmin panels
"password" filetype:logLeaked logs/creds
Blue-team note: dork your own domain to find accidental exposure; use robots.txt, auth, and Google Search Console removal for anything sensitive that's indexed.
